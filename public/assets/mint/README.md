# Mint asset drop-in

The Complete Shelf renders **procedural** clothbound covers by default and needs no
files here to run. This folder is the seam for replacing individual covers with real
artwork generated by the [Mint](https://mint.gg) asset pipeline.

## How real Mint assets get here

Mint assets are authored **out-of-band**, in an interactive session where the Mint MCP
server (`mcp.mint.gg/mcp`) is connected and authorized. The app **never** calls the MCP
from browser code — it only reads the static files you commit here.

1. In an authorized session, generate a cohesive 19-piece library of clothbound
   hardcovers (varied proportions, abstract foil motifs) via the Mint MCP in auto mode.
2. Export/download each artifact's images into `public/assets/mint/books/`.
3. Write `public/assets/mint/manifest.json` mapping each catalog book `id`
   (see `src/shelf/catalog.js`) to its images.

## `manifest.json` format

```json
{
  "version": 1,
  "books": {
    "tidal-arithmetic": {
      "front": "books/tidal-arithmetic-front.png",
      "spine": "books/tidal-arithmetic-spine.png",
      "cloth": "#3f5a54",
      "foil": "#d8b46a"
    }
  }
}
```

- Paths are relative to `/assets/mint/`.
- `spine`, `cloth`, and `foil` are optional; omit them to keep procedural values.
- Any book `id` you leave out keeps its procedural cover — you can migrate covers
  one at a time.

The loader that consumes this file is `src/shelf/mintManifest.js`.
